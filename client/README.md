# LeadPulse AI – Frontend Client Application

A modern, fast React dashboard built with Vite, Tailwind CSS, and Lucide Icons. Designed for lead tracking, role-based controls (Admin & Employee), AI score insights, and instant WhatsApp messaging.

---

## ⚡ Tech Stack

- **Framework:** React 18 (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Routing:** React Router DOM
- **Authentication:** JWT Context & Secure Token Storage
